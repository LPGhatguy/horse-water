# horse-water
you are a horse and I am leading you to water by learning new graphics techniques in the open

## you need
- dxc from the Vulkan SDK
- the desire to drink water you are led to

## why
doing these things in a smaller project to learn them:

- multi draw indirect (with count) architecture
- two-phase HiZ culling
- anything else that's easier to hack on in isolation

## whyn't
- game engine
- library

## choices
- HLSL is the shading language of serious people
